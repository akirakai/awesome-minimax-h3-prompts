- **Author:** u/No_Cow26
- **Published:** 2026-11-12
- **Final video:** approximately 60 seconds; six source shots of 260 frames / 10.8 seconds each, generated at 864×480, 25 steps
- **Video / original post / workflow:** https://www.reddit.com/r/comfyui/comments/1xtimco/this_took_x_hrs_35_mins_to_make_on_a_rtx_3050_6gb/
- **Theme:** Two students search for a book in a library and discuss its contents across a chained multi-shot sequence.
- **Prompt/workflow summary:** Reuse the same two character reference images in every shot. Write each shot with the official six-section reference prompt structure: subject definitions, summary, retention analysis, detailed description, soundscape and music. No negative prompt is used.
- **Reusable pattern:** For long base-H3 continuity, separate identity persistence from temporal handoff: static references reassert the characters in every segment, while a short audiovisual tail transfers pose, location, motion and sound into the next segment.
