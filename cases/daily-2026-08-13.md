## 3. Folder-driven multi-scene H3 movie workflow

- **Published:** 2026-08-11
- **Author:** Furkan Gözükara
- **Article / source:** [LinkedIn walkthrough](https://www.linkedin.com/pulse/minimax-h3-infinite-video-make-2-hour-movies-comfyui-0-shot-g%C3%B6z%C3%BCkara-l1kde)
- **Video:** [Full tutorial and raw workflow showcase](https://www.youtube.com/watch?v=1580ZDX-60Q)
- **Theme:** Generate many short H3 scenes from a folder of prompts and references, queue them automatically, selectively regenerate weak scenes, and concatenate them into a long movie
- **Demonstrated format:** 10-second scenes; 16:9 at 1344×768 for final generation; approximately 0.4 MP for drafts
- **H3 evidence:** The article and tutorial explicitly identify MiniMax H3, show the local workflow, and open with the raw H3-generated movie result.

### Prompt/workflow summary

1. Store one scene prompt per unit in a folder rather than asking one generation to create an entire long narrative.
2. Give recurring subjects stable reference IDs and mention only the matching IDs in each scene prompt.
3. Draft each scene at low resolution, review the assembled sequence, revise the individual prompt that failed, and regenerate only that scene.
4. Use 10-second scenes for easy review even though 15 seconds is described as the practical quality sweet spot.
5. Keep the H3 reference budget explicit per generation: up to 9 images, 3 videos, and 3 audio references.
6. Let the workflow queue, generate, and merge scenes automatically; continuity remains a prompt-and-reference responsibility rather than an automatic guarantee.

### Reusable scene-prompt template

```text
Scene [NN] — [duration] seconds
References: Image [IDs] own character identity, wardrobe, and fixed props.
Opening state: [exact composition, subject positions, environment, lighting].
Action progression: First [visible action], then [reaction/change], finally [clear end state].
Camera: [framing + movement + speed/amplitude].
Continuity: Preserve [identity/wardrobe/prop/environment details] from the assigned references.
Audio: [dialogue/foley/ambience]; music: [role or N/A].
End frame: [precise pose, composition, and motion state for the edit].
```

### Reusable pattern

Long-form H3 production is more reliable as **addressable short scenes**: fixed reference IDs, one explicit ending state per scene, draft-first review, and selective regeneration. This is operationally stronger than a single oversized prompt because failures stay isolated.
