## 3. Voice-reference dialogue without opening gibberish

- **Video, prompt screenshot, and original post:** https://www.reddit.com/r/StableDiffusion/comments/1vxpbo1/minimax_h3_gibberish_fixed_i_found_the_cure/
- **Published:** 2026-08-25
- **Author:** ndroidz
- **Theme:** a candle-lit game-character dialogue test using an audio reference for voice identity while suppressing unintended speech.
- **Available output metadata:** 16:9; exact duration and resolution were not disclosed.
- **Model evidence:** the post explicitly names MiniMax H3, embeds the generated example video, and includes a screenshot of the complete prompt.
- **Prompt original / method:** define the first speaker as `(S1) character`; declare `use <audio 1> as "character name"'s voice only`; then write each spoken line as `character says: <<[language] exact line>>`. The surrounding prompt asks for only faint candle crackle behind the specified voice.
- **Reusable pattern:** bind speaker ID, voice reference, and exact utterance separately. Constrain the ambience to a minimal named sound bed so the audio model has fewer opportunities to invent speech.
- **Important caveat:** commenters report that recent ComfyUI updates fixed tokenization of H3’s official `<d>…</d>` dialogue tags. Update ComfyUI first; treat the author’s double-angle-bracket form as a tested fallback, not a replacement for the official syntax.
