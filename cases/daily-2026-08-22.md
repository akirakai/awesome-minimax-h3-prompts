## 1. Storyboard-driven latte tutorial

- **Video and original post:** https://x.com/junwatu/status/2090804481386791109
- **Published:** 2026-08-21 23:13 JST
- **Author:** Jun Watanabe (@junwatu)
- **Theme:** an anime character prepares a latte and speaks Japanese while H3 follows a multi-panel storyboard.
- **Available output metadata:** duration and canvas were not disclosed.
- **Model evidence:** the source labels the attached result “MiniMax H3 Prompt for this video,” supplies a storyboard and character reference, and publishes the video prompt with the result.
- **Accurate prompt summary:** Treat the storyboard reference as sequential shot guidance, never as one static composition. Execute each panel as a separate beat, use the character reference only to preserve identity, and have the character deliver the specified Japanese preparation line while making the latte.
- **Reusable pattern:** explicitly state both positive and negative interpretation rules for a storyboard: “each panel is a sequential beat” plus “do not treat the board as one image.”

## 2. Two-prompt anime omurice workflow

- **Video and original post:** https://x.com/aimikoda/status/2090969477588427222
- **Published:** 2026-08-22 10:09 JST
- **Author:** Kōda (@aimikoda)
- **Theme:** an anime character makes omurice by following a rough storyboard created from the same character reference.
- **Available output metadata:** duration and canvas were not disclosed.
- **Model evidence:** the creator explicitly calls the result “MiniMax H3 Anime with Storyboard,” attaches the generated video, and publishes both the storyboard-image prompt and the H3 instruction.
- **Prompt originals:** storyboard image: “Create a rough sketch omurice-making storyboard with the given character.” H3 then receives the storyboard as sequential-shot guidance rather than a static image and is told to follow each panel as a separate beat.
- **Reusable pattern:** keep the upstream storyboard deliberately rough and simple; assign character design to the identity reference and shot order to the board, then make that role separation explicit in the H3 prompt.
- **Deduplication note:** this uses the same storyboard-control grammar as the latte case above, but it is a distinct video, subject, character, and source. Both are grouped as one prompting family rather than counted as two unrelated techniques.

## 3. Hand-drawn scrambled-eggs explainer with readable text

- **Video and original post:** https://x.com/MrDavids1/status/2090548199861690859
- **Published:** 2026-08-21 06:15 JST
- **Author:** Travis Davids (@MrDavids1)
- **Theme:** a concise educational cooking explainer in a soft hand-drawn 2D style.
- **Available output metadata:** 15 seconds; canvas was not disclosed.
- **Model evidence:** the original caption repeatedly names MiniMax H3, attaches the generated explainer, and publishes the production prompt. MiniMax Design also surfaced the same example.
- **Accurate prompt summary:** Create a clear fifteen-second tutorial with gentle hand-drawn outlines. Begin by cracking two eggs into a transparent bowl; preserve both eggs visibly as whisking starts; build to whisking, melting butter in the pan, and cooking the eggs; finish with a legible conclusion. Give the sequence a beginning, climax, and end, and render the instructional text in bold sans-serif type.
- **Reusable pattern:** for process explainers, define object-state continuity between steps, a narrative arc, and typography rules together; this is more robust than listing isolated recipe actions.

## 4. Pre-generated branching corgi adventure

- **Interactive video demo and original post:** https://www.reddit.com/r/StableDiffusion/comments/1vurrua/not_realtime_but_feels_realtime_a/
- **Published:** 2026-08-22; exact time was not exposed by the public page
- **Author:** super3
- **Theme:** a choose-your-own-adventure corgi story built from a tree of H3 clips.
- **Available output metadata:** fourteen scenes, two paths, seven endings; each scene is a 15-second MiniMax H3 clip with synchronized audio. Choices appear at ten seconds.
- **Model evidence:** the author states that every scene is a MiniMax H3 generation, links the working interactive demo, and explains the generation and handoff pipeline.
- **Accurate prompt/workflow summary:** Generate each branch with first-and-last-frame-to-video. Use the accepted parent clip’s final frame as the child clip’s exact starting image, write each child as a complete fifteen-second story beat with synchronized audio, and ensure it reaches a choice-ready state by ten seconds. Pre-generate and cache both possible child clips while the parent plays.
- **Reusable pattern:** continuity comes from a shared boundary frame rather than an increasingly long prompt. For interactive narratives, combine exact frame handoff, fixed decision timing, speculative preloading, and one independent prompt per branch.
- **Cost/runtime notes from the source:** fastest test was about 22 seconds to generate a five-second clip on one GPU; the complete pre-rendered tree cost about USD 2.50.
