- **Available output metadata:** the tutorial is 11 minutes 22 seconds. Demonstration generations use 5-second clips, 0.2 MP input and output, 8 steps, and an RTX 3080 with 16 GB VRAM plus 64 GB RAM; the author reports about 12 minutes per 5-second edit.
- **Model evidence:** the title and description explicitly identify MiniMax H3. The author states that both video-editing workflows load the pruned int8 ConvRot reference model, use eight steps, and run without Turbo LoRA, SageAttention, BlockCache, or Spectrum acceleration.
- **Workflow and prompt strategy, accurately transcribed:** For the mask path, upload a source video, let SAM 3.1 identify a named moving region such as “head,” track and crop that mask through the clip, and pass the crop plus an optional replacement image into H3 Ref2VA. The prompt separately defines Picture 1, Video 1, the replacement goal, the replacement subject, and the retained action. Paste the edited crop back into the original frame. For instruction editing, supply the whole video and zero or more object images, then say what to add, replace, or preserve; transparent or white image backgrounds work best. Keep both source and output at the same low megapixel setting. For low-memory image-to-video quality, render a 0.2 MP first pass and perform a separate latent upscale near 0.7 MP; do not add that upscale to the more memory-heavy video-to-video paths.
- **Reusable pattern:** separate localization from generation. Let a tracker own where the edit happens, a reference own what the replacement looks like, the source clip own motion and untouched regions, and the text own the edit instruction. Match input and output scale during video editing, then move quality recovery to a separate pass only when memory permits.
